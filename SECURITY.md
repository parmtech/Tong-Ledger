# Reporting Security Issues

**Do not post vulnerabilities or private financial details in public GitHub issues.** Use GitHub's private vulnerability reporting feature if enabled for this repository; otherwise contact ParmTech privately through an official published support channel. Do not include real customer financial information in reports. Supported versions: none yet; the project is pre-release. Avoid running the early demo with real data until encryption, secure backups and external review are complete. See [Security & privacy plan](docs/SECURITY_PRIVACY.md).
