# Contributing to Tong Ledger

Thank you for helping build an open-source personal finance app. Please start with the [master blueprint](docs/MASTER_BLUEPRINT.md), [architecture](docs/ARCHITECTURE.md) and [handoff](docs/HANDOFF.md). Submit issues with reproductions using **fictional** account details only. Keep changes scoped to one feature, add automated tests and explain changes. Run flutter format, flutter analyze and flutter test when SDK is available. Money calculations must avoid floating point and preserve transaction audit history. Review privacy, accessibility, license and multi-platform impact before merging. Do not upload real bank documents, screenshots showing account details, credentials or copyrighted assets without permission. We follow respectful and inclusive code review. The project is Apache-2.0 licensed.
